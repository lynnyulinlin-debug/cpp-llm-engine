# Foundation

This section prepares the background you need before the main line.

## What it is for

- C++ language basics, ownership, and lifecycle
- Build system and environment setup
- Debugging and testing habits
- Design and data-layout thinking
- A small project that closes the foundation loop

## How to use it

- Read the pages in order if you are new to the stack.
- Skip ahead if you already know a topic well enough.
- Return here only when the main line exposes a gap you need to fill.
