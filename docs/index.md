## 这是什么

这是一个面向中文学习者优先的 C++ LLM 推理教程。  
如果你想先知道怎么读，先看 [阅读指南](/guide)；如果你想直接看主线，从 [教程主入口](/README) 进入。

## 你会看到什么

- `foundation` 到 `chapter07_benchmark` 的主线
- 训练框架、推理框架和本教程的对照层
- 术语表、写作规范和维护规范
- 图示、表格和收口页

## 适合谁

- 想从零看懂推理引擎的人
- 想理解 runtime、KV Cache、benchmark 证据链的人
