# Chapter 01: Tensor Loader

This directory contains the minimal reference implementation for
`chapter01_tensor_loader`.

## Scope

- Tensor abstraction
- Tensor memory implementation
- Custom binary format helpers
- Python conversion script support
- ModelLoader implementation
- Load verification utilities
- The loader establishes the first trusted input boundary for the rest of the tutorial

## Notes

Keep the code aligned with the documentation in `docs/chapter01_tensor_loader`.
The current implementation includes a minimal Tensor model, a simple
ModelLoader, and a local test entry point.
