# Summary Template 章节收口模板

这个模板用于 `summary.md`。目标是让中文主线更稳定，同时给非中文母语学习者留出最小但有用的英文锚点。

## 建议结构

### 1. 本章解决了什么

- 用中文说明这一章解决的核心问题
- 用 2 到 4 句把边界讲清楚

### 2. 为什么它重要

- 说明这一章为什么现在必须出现
- 说明后续章节依赖它什么

### 3. 背景回顾

- 用一小段话回顾这一章最关键的背景
- 说明读者为什么在这里需要它

### 4. 中间推导回顾

- 回顾这一章是怎么从问题走到方案的
- 说明最关键的设计转折点是什么

### 5. 你现在应该能做什么

- 列出本章完成后的可验证能力
- 尽量写成读者视角，而不是实现视角

### 6. 边界说明

- 明确这一章不做什么
- 明确哪些更复杂的问题留给后续章节或附录

### 7. 下一步是什么

- 用一句话说明自然的下一章
- 说明为什么它是顺着来的，不是硬切的

## 建议的英文锚点

英文锚点不需要长，只要稳定即可。可以保留下面四项：

- `Problem`
- `Why it matters`
- `Background`
- `Derivation`
- `Verification`
- `Next step`

## 示例写法

```md
## 本章解决了什么

...

## 为什么它重要

...

## 背景回顾

...

## 中间推导回顾

...

## 你现在应该能做什么

...

## 边界说明

...

## 下一步是什么

...
```

## 维护原则

- 中文正文负责讲清楚内容
- 英文锚点负责帮助导航
- 不在收口里重复全文
- 每章保持同一结构，不随意变体
- 背景和中间推导不是可选项，正文里应稳定保留
