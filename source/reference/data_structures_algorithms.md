# 数据结构与算法资产表

这张表按“可实现资产”整理教程中的数据结构和算法。它回答三个问题：资产解决什么问题、代码和验证在哪里、学完后应如何映射到真实推理框架。

需要跨章节查找同类对象时使用本表；单章的文件和练习入口从对应章节 README 进入。

## 怎么读

- 初学者按“首次出现章节”顺序学习，先看正文，再运行“验证产物”。
- 进阶读者从“真实框架对应物”反查 vLLM、SGLang、TensorRT-LLM、llama.cpp 的同类设计。
- “教程实现与验证”列说明可以运行的教学实现、验证入口或外部参考适配；它不表示生产部署能力。

## 阅读顺序

先用 `Storage -> Tensor view -> Matrix -> MatMul` 建立数值计算主线，再用 `Request -> KVCache -> Scheduler -> Runtime` 建立生成主线，最后用 `BlockTable -> quantized Linear -> benchmark/profile` 连接内存优化和性能证据。Chapter09 的 `ResponseWriter` 与 `ServiceCore` 放在运行时稳定后学习。
