# SGLang 应用编排

## 解决什么问题

`SGLang` 主要解决的是更高层的应用编排和结构化 serving 问题。它适合回答这样一个问题：如何把模型调用组织成一个更复杂、更可控的应用运行时。

## 工程策略

- 强调应用级编排
- 支持结构化生成和多步运行逻辑
- 关注模型调用与上层 workflow 的衔接

## 什么时候选它

如果你的问题不是单纯的吞吐，而是“如何把多个模型调用步骤组织成一个更高层的服务流程”，就可以优先看 `SGLang`：

- 需要更强的应用编排能力
- 需要结构化生成
- 需要把 serving 和应用 workflow 连起来
