# 01.5 ModelLoader 模型加载器


## 这一页要解决什么

实现 C++ `ModelLoader`，把自定义格式文件解析成程序内部的 `Tensor` 集合。

## 读完你应该能做什么

- 理解 loader 的职责边界
- 理解如何从文件读取 tensor table 和 data region
- 理解如何把文件内容组织成可访问的内存对象

## 为什么这一步重要

这一页把“文件格式”真正转成“程序可用数据”。没有 loader，格式只是文档；有了 loader，后面的算子才能吃到真实权重。

## 核心职责

- 打开模型文件
- 校验魔数和版本
- 读取 tensor 元信息
- 构建 tensor map
- 提供按名称访问 tensor 的能力

## 设计要点

- 错误处理要清晰
- 读取逻辑要可扩展
- 不要把 loader 写成一堆全局状态
- 保留后续支持量化格式的空间

`ModelLoader` 的工作不是“把文件读出来”这么简单，而是把文件里分散的元信息和数据区域组织成可以按名称访问的内存对象。换句话说，它在做的是把静态文件转换成运行时结构。

这也是为什么错误处理要尽量清晰：一旦读错了，后面每个算子都可能连带出问题。

## 怎么验证

- 能成功加载完整模型文件
- 能按名称找到 tensor
- 能打印 tensor 的 shape 和 dtype

如果你能通过名称快速定位某个权重，并确认它的元信息与文件内容一致，loader 基本就已经完成使命了。

## 常见问题

- 文件头读取错误
- tensor 偏移计算错误
- 名称和数据映射不一致
