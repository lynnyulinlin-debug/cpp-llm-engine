# Guides 开发参考

这里放的是写代码、接数据、做迁移时最常查的工程参考。它面向“正在实现功能”的读者，而不是纯概念阅读者。

## 内容范围

- [cmake_guide.md](/guides/cmake_guide)：CMake 常用技巧
- [setup_cuda.md](/guides/setup_cuda)：CUDA 安装与配置
- [gtest_migration.md](/guides/gtest_migration)：Google Test 迁移预案
- [gguf_parser.md](/guides/gguf_parser)：GGUF 解析与加载器实现
- [language_strategy.md](/guides/language_strategy)：中文优先与英文入口的语言策略

## 怎么用

- 开发时遇到构建、环境或测试迁移问题，先看这里
- 这些页面是工程参考，不是主线正文
- 如果你在读主线教程，只在遇到具体工程问题时回来看
