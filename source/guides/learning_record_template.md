# 学习验收记录模板

每完成一项学习任务，保存一份可复查记录。记录用于证明运行条件、输入和结果，不要求粘贴完整构建日志。

建议文件名包含日期和主题，例如 `2026-10-19-real-decoder.md`。文件可以保存在个人学习目录，不需要提交到教程仓库。

## 解释

用自己的语言回答：

1. 数据从哪里进入，经过哪些主要对象？
2. CPU reference 或上一阶段基线是什么？
3. 本次验证证明了什么，不能证明什么？
4. 如果失败，最先检查哪个输入、contract 或资源状态？

## 遗留问题

记录尚未理解的问题、未运行的可选路径和下一次准备验证的单一变化。
