# Language Strategy 语言策略

本文档定义这套教程面向中文读者优先、同时保留英文入口的语言组织方式。

## 1. 目标

这套教程的目标不是把所有内容都做成双语，而是让两类读者都能有效使用同一套内容：

- 中文读者默认顺畅阅读主线
- 非中文母语学习者可以通过英文入口、固定结构和术语表跟读主线

## 2. 总体原则

### 2.1 中文主线优先

- 正文、桥接和收口以中文为主
- 章节目标、问题陈述、实现解释和 tradeoff 分析都优先写中文
- 不在正文里堆大段英文模板

### 2.2 英文入口保留

- 根目录 `README.md` 以中文优先
- `docs/README.md` 作为中文主入口
- `docs/README.en.md` 作为轻量英文导航页
- `USAGE.md` 以中文说明阅读路径

### 2.3 术语统一

- 概念第一次出现时给出中文解释和英文原词
- 术语保持固定写法，不在不同章节里反复变体
- 代码标识、命令、类名和函数名保持英文

### 2.4 结构稳定

英文学习者更依赖结构，因此每章尽量保持固定骨架：

- 问题是什么
- 为什么重要
- 怎么做
- 怎么验证
- 本章收口

即使正文是中文，这些位置也要长期稳定。

## 3. 面向英文学习者的辅助层

英文学习者不需要等到全文翻译完成才开始使用这套教程。建议依次使用下面几层：

1. 英文入口页，先判断全局结构
2. 章节 `intro.md`，先理解问题和目标
3. 章节 `summary.md`，先抓住收口和下一步
4. 术语表 [glossary.md](../reference/glossary.md)，先统一概念
5. 正文，按章节需要逐步阅读

## 4. 推荐的维护方式

- 新增章节时，先按中文主线写清楚
- 如果需要照顾英文学习者，优先补摘要层和术语层，而不是先全文双语
- 当某个章节对英文学习者特别关键时，再考虑加少量英文锚点
- 如果后续反馈显示英文入口不够清晰，再补导航，不先改动整套正文

## 5. 不建议的方式

- 全文中英并排
- 每章自由决定是否双语
- 同一个概念在不同页面用不同英文写法
- 让英文入口和正文主线分叉成两套教程

## 6. 实施优先级

1. 保持中文主线稳定
2. 保留英文入口页
3. 统一术语和章节结构
4. 给摘要页加英文锚点
5. 视反馈决定是否补术语表和更多英文说明

## 7. English summary

- Chinese-first main line
- English navigation preserved
- Stable structure and terminology
- Add English anchors only where they help navigation and comprehension
